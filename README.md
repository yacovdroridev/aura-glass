# aura-glass

Transparent "glass" GTK4 theme overrides for GNOME (Ubuntu 26.04, Wayland).

- Translucent windows with dark tint
- Desktop window (Gtk4 Desktop Icons `gtk4-ding`) kept transparent, so the wallpaper isn't darkened
- Desktop icon hover/click effect (scale + fade)

Note: GTK CSS ignores `!important`; overrides use `window#desktopwindow` id selectors.

## Install
```sh
./install.sh
```
